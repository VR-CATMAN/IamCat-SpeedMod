## 🐾 IamCat SpeedMod
I made a high-speed mod that doubles the walking speed of I Am Cat NPCs!
Enjoy more thrilling chases
I am also looking for improved versions, so please feel free to send me a pull request

### Required environment
- I Am Cat (Version: 1.1.0.3)
- MelonLoader v0.6.6 Open-Beta

### Installation procedure
1. Install SpeedMod from the following link <br>
https://github.com/VR-CATMAN/IamCat-SpeedMod/releases/tag/v1.0.0

2. Install Melonloader in the folder that contains the I Am Cat exe file <br>
Example: C:\SteamLibrary\steamapps\common\I Am Cat\

3. Paste SpeedMod.dll into the Mods folder in that folder (create a Mods folder if it does not exist)

4. Start I Am Cat and if the NPCs (such as the grandmother) move faster, it's OK.
